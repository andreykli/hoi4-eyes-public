# Минимальная публикация — только вручную после разрешения владельца

Подготовка ничего не загружает. Старый приватный репозиторий не трогать.
Для публикации использовать только отдельную чистую копию и её файлы.

## Профиль модели

Выбран локальный qwen3:4b-instruct с Apache-2.0. Старый 3B не является
публичным профилем. См. MODEL_LICENSE.md и release/model_profile.json.

## GitHub

1. Создайте **пустой** публичный andreykli/hoi4-eyes-public в своём аккаунте:
   не добавляйте на сервере README, LICENSE или начальный коммит.
2. Из чистой локальной копии отправьте ветку main и тег v0.9.0-beta.1.
   Remote origin уже указывает на новый адрес. Не выполняйте эти команды
   из старой папки app и не используйте force-push:

   `git push -u origin main`

   `git push origin v0.9.0-beta.1`

3. Создайте Release по этому тегу, включите **Pre-release**. Заголовок и текст
   находятся в docs/GITHUB_RELEASE.md. Приложите только подготовленные ZIP
   из artifacts, SHA256SUMS.txt и checksums.json. Приватный исходный каталог
   или его .git не загружать. Короткое описание — docs/GITHUB_PUBLICATION.md.

## Steam Workshop

1. Проверьте визуально предложенную обложку и короткую игровую приёмку из
   docs/BETA_ACCEPTANCE.md. Картинка — кандидат, не финально утверждённый материал.
2. При закрытой игре откройте её лаунчер. В разделе создания/загрузки модов
   создайте локальную запись для подготовленной чистой папки Workshop.
   Если лаунчер требует создать свой каталог, перенесите в него **только содержимое
   подготовленного пакета**, а не рабочий мод с личными договорами.
   Названия пунктов зависят от версии лаунчера; используйте его штатный Upload mod.
3. Выберите HOI4-EYES, версию 0.9.0-beta.1 и целевую игру 1.19.5.*.
   Внешний launcher descriptor может содержать локальный path; во внутренний
   descriptor.mod абсолютный путь не записывать. remote_file_id впервые
   назначает Steam — не выдумывать его заранее.
4. Вставьте описание из docs/WORKSHOP_PUBLICATION.md, укажите GitHub и загрузите
   утверждённую обложку. Примите необходимые условия своей учётной записью.
   Это действие создаёт публикацию; автоматическая подготовка его не выполняла.
5. После получения настоящей ссылки Workshop добавьте её в NOTICE, CREDITS,
   ATTRIBUTION и описания. Для чистого репозитория подготовлен инструмент:

   `python tools/update_workshop_link.py --url https://steamcommunity.com/sharedfiles/filedetails/?id=ЧИСЛОВОЙ_ID`

   Он меняет только локальные тексты и PUBLICATION.json, не загружает ничего,
   не коммитит и не перемещает релизный тег. Обновлённые файлы можно выпустить
   отдельным коммитом/обновлением; ZIP и хеши после изменения нужно пересобрать.

## Что остаётся проверить человеку

Чистый запуск Windows-приложения; текущий GER–POL многопунктный договор;
реальный пакт и одна новость; выбор/отмена столицы после смены дня;
карта признания и отсутствие наложений RU/EN/FR. Исторический QA 21/21 и
автоматические проверки не заменяют эти экраны. Публикация beta допустима
с честно обозначенными ограничениями, а не с обещанием готовой 1.0.
