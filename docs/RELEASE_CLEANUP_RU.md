# Очистка состава beta.2

Проверены реестр поставки, импорты Python, потребители шаблонов, запуск служб,
игровые локализации, регистрация лаунчера и путь публичного обновления.

Удалены 11 неиспользуемых импортов после поиска зависимостей. Старый личный
архив договора исключён из текущего состава Git; сам файл на диске сохранён.
Инструкции первой публикации beta.1 заменены инструкциями обновления.
Устранены старый жёстко заданный тег beta.1 и возможность создания нового
Workshop-предмета. Перед загрузкой проверяются байты папок относительно архивов.

Сохранены используемые experimental_stack и experimental_hub: это рабочие
части запуска и Flask. Старые каталоги фраз используются другими ответами,
новостями и языками. Неочевидный межмодульный импорт оставлен для совместимости.
Частные QA-модули и фикстуры сохранены в разработческой копии, но исключены
из поставки. Старые сборки сохранены для отката.

Логи, настройки, SQLite, снимки, сохранения, резервные копии и Acceptance
не удалялись и в публичные архивы не включаются. Частная история Git
не переносится. Обновление создаётся поверх отдельной публичной истории.
Полная новая игровая приёмка не выполнялась; это beta, а не стабильная 1.0.
