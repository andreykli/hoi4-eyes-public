# HOI4-EYES — Local AI Diplomacy & Government

Draft for Steam Workshop and GitHub. Not published.

EN: Negotiate with countries and consult your government through a local AI.
EYES combines conferences, diplomatic memory, an Atlas, typed game actions and
news. Beta targets HOI4 1.19.5.0. Python, Ollama and the companion app install
separately; a Workshop subscription alone is insufficient. Not every proposal
can execute; some changes require a restart. Start with a disposable campaign.

Beta для HOI4 1.19.5.0. Python, Ollama и приложение устанавливаются отдельно:
одной подписки Workshop недостаточно. Не все предложения исполнимы; часть
изменений требует перезапуска. Начните с новой тестовой кампании.
