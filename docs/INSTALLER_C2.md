HOI4-EYES 0.9.0-beta.3 — Experimental Installer C2
By NightPulse. HOI4 1.20 compatibility work remains beta; new game acceptance is incomplete.

NEW USERS: Subscribe, open this Workshop folder and manually run Install HOI4-EYES.exe.
Close HOI4, EYES and the Paradox launcher first. Approve each missing component separately.
This item includes an UNSIGNED Windows EXE, Python source and dependency wheels.
Python, WebView2, Ollama and Qwen may require official downloads with your consent.
Nothing installs or launches automatically on subscription. Do not disable Windows security.

EXISTING USERS: Run setup once and choose Update / repair. Existing shared SQLite,
treaties, settings, history and models are preserved. Select an old GitHub source folder
if necessary. Import local history only into an empty profile; conflicting profiles
require review. Keep old folders and backups. Keep one managed local EYES mod enabled;
the subscribed Workshop copy supplies updates. Disable Acceptance without deleting it.

UNINSTALL: Windows Settings > Apps > Installed apps > HOI4-EYES opens the saved wizard.
Confirm removal there. Profiles, models, shared runtimes and recovery copies remain.
Unsubscribing alone does not uninstall the companion app.

LIMITATIONS: No Authenticode signature. Clean-Windows/vendor-installer and real-launcher
acceptance are incomplete. This is an owner-authorized experimental beta, not certification
by Valve or Paradox. Native setup is Windows x64. Allow at least 8 GB free for a clean
installation, caches and model. Existing compatible components can be reused.
Automatic execution of a new unsigned updater is disabled; updates require manual approval.
