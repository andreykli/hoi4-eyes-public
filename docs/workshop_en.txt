[b]NightPulse | 0.9.0-beta.6 | HOI4 1.20.0.0[/b]

The existing diplomacy window opened from HOI4 now supports 1–6 counterpart countries, saved groups and sequential Qwen replies. The player speaks first; treaties still require confirmation.

Beta.2: mandatory independent treaty decisions, resistance to prompt manipulation,
faster typed proposals and 540 original EN/RU/FR wording entries. Qwen selects wording;
it cannot turn refusal into acceptance. Recognition and public UI labels are fixed.
HOI4 1.20 scripts were reviewed; complete main-mod live acceptance remains pending.
Internal QA executors are excluded from the public distribution.


Talk to countries, negotiate precise treaties and consult your government with
a local AI. HOI4-EYES combines a Windows companion with guarded game scripts.

Features: diplomatic chats and conferences; revision-specific confirmations;
supported pact, guarantee and access actions; Bridge receipts and repeat protection;
diplomatic memory and news; Atlas, Recognition Atlas and Country Maker;
government discussions and fleet planning templates. EN/RU/FR interface.

IMPORTANT: Workshop contains the game mod, not the AI backend. Download the
Windows-source companion separately. Install Python 3.10+, WebView2 and Ollama;
download qwen3:4b-instruct, run setup_windows.bat once, then start.bat.
No paid AI API is required. Enable one EYES copy only. The companion currently
manages a writable bundled local mod: do not enable its local copy together
with the Workshop subscription. See the companion README for registration.

Beta limits: not every proposal has a game executor. Some installations require
restarting HOI4. A signature is not game confirmation. Modified maps require
geometry validation; fleet templates and many reforms remain advisory. Multiplayer,
Ironman/achievements and all DLC/playset combinations are not certified.
First use: a disposable campaign. Keep backups of important saves.
