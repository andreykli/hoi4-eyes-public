# Кандидат 0.9.0-beta.2: доказательства и ограничения

Подготовка публичного обновления 0.9.0-beta.2. Статус публикации подтверждается отдельно сервисами.
Финальный полный прогон: 1477 тестов, 0 падений и исключений. Статический
аудит основного мода, объединённой сборки, наблюдателя и нативного пакета:
0 ошибок, 0 предупреждений. GUI, сквозные HTTP/Bridge/SQLite-проверки
и повторное воспроизведение квитанций прошли офлайн.
Полный набор тестов и сквозные лаборатории запускаются через
`tools/offline_quality_gate.py --game-dir <HOI4> --full-tests`.
Машинный отчёт сохраняется в runtime/tmp/quality_gate_*/report.json.
Публичная поставка содержит отдельные проверки целостности; личные данные,
пользовательские базы и частная история Git в неё не включаются.

Исправлены порядок политических проверок при подписи/подготовке, передача
памяти временным исполнителям, обработка Retry и старых подписей. Защита
обязательна для всех способов запуска; неизвестные данные откладывают подпись.
Идеология требует подтверждения Bridge. Память и интересы кампаний изолированы.
Новый пакет со старым неоднозначным направлением обязательства блокируется,
но исходная редакция, подписи и переписка сохраняются.

Лаборатория с локальной qwen3:4b-instruct прошла восстановление истории и
защиту от исполнения неисполнимых условий. Это настоящие вызовы локальной
модели и Flask, но синтетическая игровая ситуация, а не HOI4.

Прежний отдельный нативный QA HOI4 1.19.5.0: 21/21 PASS, Bridge 21/21.
Прежние игровые результаты не подтверждают новый основной кандидат.
Совместимость 1.20 проверяется по установленной документации и скриптам.
Повторный запуск HOI4 1.19.5 здесь не выполнялся.

Для стабильной 1.0 остаётся реальная приёмка основной сборки:
GER–POL с тремя условиями, согласия, подпись, установка, три игровых эффекта,
квитанции Bridge, одна новость и отсутствие повторного исполнения. Затем
Atlas, Country Maker, столица и RU/EN/FR. См. BETA_ACCEPTANCE.md.
Beta.2 выпускается с явно указанной незавершённой приёмкой. Стабильная 1.0 до её завершения не готова.

Публичный интерфейс: роли, темы и режимы локализованы на EN/RU/FR.
Игровые QA-исполнители и панель разработчика не включены в публичную поставку.
PyWebView обычной сборки не предоставляет методов QA; сервер отвергает
диагностические запросы. Частная разработческая сборка требует локального
подписанного разрешения владельца. Пользовательского переключателя нет.

Состав поставки очищен от внутренних QA-исполнителей; 11 неиспользуемых импортов удалены. Старый личный архив сохранён на диске, но исключён из Git. См. RELEASE_CLEANUP_RU.md и DIPLOMATIC_LATENCY_RU.md.
