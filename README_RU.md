# HOI4-EYES Beta


Локальная ИИ-дипломатия и обсуждение управления государством для Hearts of Iron IV.
Автор: **NightPulse** · [Оригинал](https://github.com/andreykli/hoi4-eyes-public).

[English](README.md) · [Français](README_FR.md)

**0.9.0-beta.1 — публичная beta, не готовая версия 1.0.** Целевая среда:
Windows, HOI4 **1.19.5.0**, Python 3.10+, Ollama `qwen3:4b-instruct`.
Собственное окно работает через PyWebView/WebView2 и существующий Flask.
Платные API не нужны; при стандартных настройках модель работает локально.

## Установка

1. Установите Python с Windows launcher, Ollama и WebView2 Runtime.
2. Один раз выполните `ollama pull qwen3:4b-instruct`. Для загрузки нужен
   интернет. Модель и её лицензия не входят в архив.
3. Распакуйте Windows source в доступную для записи папку. Один раз запустите
   `setup_windows.bat`, затем используйте `start.bat`.
4. Проверьте готовность служб. Через существующее управление установкой
   зарегистрируйте локальный мод при закрытой HOI4. Включите одну копию EYES.
5. Создайте одноразовую кампанию для первого теста. QA-мод включается отдельно.

Игра автоматически не запускается. Это исходное Python-приложение, не подписанный EXE.
Не перезаписывайте старую установку без копии. История и настройки остаются в
`%LOCALAPPDATA%/HOI4-EYES`; распаковка их не очищает.

## Возможности и ограничения

- Чат и конференции 2–6 стран, редакции условий, структурированные решения
  Ollama, отказы, уточнения и встречные предложения.
- Подписание, игровые пакеты, установка после выхода, квитанции Bridge,
  защита от повторов, дипломатическая память и генерация новостей.
- Atlas, Recognition Atlas, Country Maker, совещания, проекты, пресса,
  морская панель и шаблоны. Выбор интерфейса EN/RU/FR.

**Согласование не означает исполнение.** Нужны подтверждения одной редакции
всех обязательных сторон. SIGNED/PREPARED/SENT не подтверждают игровой эффект.
Неподдерживаемое условие блокирует исполнение. Часть маршрутов требует закрыть
игру, установить скрипты и запустить её снова. Bridge проверяет результат.
Совещания, реформы и морские шаблоны сами по себе игру не меняют.
Территориальные действия на неподтверждённой геометрии заблокированы.

Ранее отдельный игровой QA на 1.19.5.0 дал **21/21 PASS, Bridge 21/21**.
Это не проверка всех экранов и текущих чистых архивов. См. [инструкцию](docs/BETA_GUIDE.md),
[приёмку](docs/BETA_ACCEPTANCE.md), [изменения](CHANGELOG.md), [Workshop](docs/WORKSHOP.md).
